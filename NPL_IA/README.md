# Módulo NPL_IA - Nuevo Asistente Virtual Inteligente (Rama popu-chat2)

Esta carpeta está destinada a contener todo el material, documentación, reglas y recursos del práctico evaluativo para la integración de la IA en **PopuChat 2**.

---

## 📂 ¿Qué puedes colocar en esta carpeta?
- **Consignas del práctico:** Archivos PDF, Word, imágenes o texto con las pautas de la cátedra/evaluación.
- **Nuevas Reglas del Bot:** Casos de uso, árboles de decisión, políticas de respuesta o restricciones.
- **Prompts del Sistema (System Prompts):** Instrucciones de personalidad, tono y comportamiento para el modelo de IA.
- **Datasets o Ejemplos:** Preguntas y respuestas modelo para pruebas y evaluación.
- **Credenciales / Variables de entorno (.env):** (Asegurarse de mantener las API keys en `.gitignore`).

---

> 🚀 **Estado:** Rama `popu-chat2` activa. Todo el material colocado aquí quedará versionado de forma segura y separada del Popuchat original.
